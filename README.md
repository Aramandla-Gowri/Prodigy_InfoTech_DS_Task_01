# Prodigy InfoTech Data Science Internship - Task 01

## Project Overview
This repository contains the first task of my Data Science internship at **Prodigy InfoTech**. The objective of this task was to create a visualization that represents the distribution of a variable (Population) across different countries using a Bar/Column Chart.

## Task Objective
* **Goal:** Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable.
* **Dataset:** World Population Data (2022).
* **Tool Used:** Microsoft Power BI.

## Key Features of the Dashboard
- **Total Population by Country:** Visualized using a Column Chart to show the top countries.
- **Data Formatting:** Applied custom colors and data labels for better readability.
- **Interactivity:** The chart allows users to see the exact population figures for each nation.

## Files Included
- `worldpopulationdata.csv`: The raw dataset used for analysis.
- `Prodigy_Task_01.pbix`: The original Power BI Desktop file containing the data model and visuals.
- `Prodigy_Task_01.pdf`: An exported PDF version of the final dashboard for quick viewing.

## How to View
1. Download the `.pbix` file and open it in **Power BI Desktop**.
2. Alternatively, you can view the static report by opening the `.pdf` file.
